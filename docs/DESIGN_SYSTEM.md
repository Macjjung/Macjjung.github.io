이 문서는 전체 포트폴리오 디자인 시스템의 단일 기준 문서다. Canvas, Typography, Grid, 공통 영역, Layout ID, 컬러 및 디자인 검수 규칙은 이 문서를 따른다. REFERENCES.md는 시각적 영감을 제공하며 이 문서의 규격을 변경하지 않는다. 콘텐츠의 사실과 수치는 CONTENT.md를 따른다.

## 2. Visual Direction

전체 포트폴리오는 Riddes를 주요 시각적 레퍼런스로 사용한다.

목표 디자인은 다음과 같다.

- Editorial Product Case Study
- 정돈된 그리드 기반의 모던한 레이아웃
- 강한 타이포그래피와 명확한 정보 위계
- 여백을 활용한 시각적 리듬
- 불필요한 장식이 없는 그래픽 구성
- 데이터와 텍스트가 조화를 이루는 편집 디자인

Riddes의 시각적 스타일을 참고하되, 원본 디자인을 그대로 복제하지 않는다.

16:9 프레젠테이션에 맞게 재구성한다.

## 3. Color System

### Base Colors

- Background: #FFFFFF
- Primary Text: #172033
- Secondary Text: #526071
- Surface: #F5F7FA
- Divider: #E2E6EC

### Coupang-Inspired Accent Palette

- Brown: #894F24
- Red: #E94B22
- Yellow: #FAC000
- Green: #80BC27
- Blue: #3DACDC

위 색상은 쿠팡의 다색 로고를 참고한 포트폴리오용 팔레트이다.

### Color Usage

- 전체 배경은 흰색 중심으로 구성한다.
- 본문은 어두운 중립 색상을 사용한다.
- 주요 KPI에는 Blue 또는 Red를 선택적으로 사용한다.
- 긍정적 성과를 무조건 Green으로 표현하지 않는다.
- 차트의 색상은 데이터의 의미와 비교 관계를 기준으로 선택한다.
- 모든 Accent 컬러를 한 슬라이드에서 사용하지 않는다.
- 프로젝트마다 완전히 다른 컬러 테마를 적용하지 않는다.

### Multicolor Sequence

쿠팡 로고의 컬러 배열에서 착안한 다음 시퀀스를 사용한다.

Brown → Red → Yellow → Green → Blue

적용 가능한 요소:

1. 표지 하단 또는 상단의 얇은 컬러 스트립
2. 챕터 구분 페이지의 컬러 인덱스
3. 전체 포트폴리오 목차의 순서 표시
4. 프로젝트 간 내비게이션 요소

이 배열은 장식적 목적의 포트폴리오 그래픽으로 사용하며, 실제 쿠팡 로고를 변형하거나 재제작하지 않는다.

## 4. Canvas & Grid

- Canvas: 1920×1080px, Aspect Ratio: 16:9
- 좌표 원점은 슬라이드 좌측 상단이며, 모든 좌표와 크기는 논리적 px 기준이다.
- 좌우 안전 여백: 각각 96px. 콘텐츠의 가로 범위는 X96~1824, 너비는 1728px이다.
- Grid: 12-column grid, gap 24px. 열 너비는 (1728 − 24 × 11) ÷ 12 = 122px이다.
- 모든 슬라이드는 동일한 좌표계를 사용한다.
- 브라우저에서는 슬라이드 전체를 비례 확대·축소한다. 화면 크기에 따라 내부 구조를 재배열하지 않는다.

## 5. Typography

표의 크기는 font-size, 굵기는 font-weight이며 행간을 의미하지 않는다.

| Token | 크기 | 굵기 | 용도 |
|---|---:|---:|---|
| Display | 84px | 700 | 표지 및 섹션 구분의 대표 문구 |
| H1 | 52px | 700 | 일반 콘텐츠 슬라이드의 핵심 메시지 |
| H2 | 32px | 600 | 본문 주요 소제목 |
| H3 | 26px | 600 | 본문 세부 소제목 |
| Body | 25px | 400 | 본문 설명 |
| Caption | 19px | 400 | 데이터 출처, 비교 기준, 보조 설명 |
| KPI | 80px | 700 | 핵심 성과 수치 |
| Header / Footer | 18px | 500 | 공통 상단·하단 정보 |

- 제목 길이에 따라 글자 크기를 임의로 줄이지 않는다.
- 텍스트가 넘치면 내용을 재구성하거나 슬라이드를 분할한다.
- 행간과 줄바꿈은 지정 영역 안에서 가독성과 비중첩을 확보하도록 적용하고 실제 렌더링으로 확인한다.

## 6. Shared Structure & Fixed Coordinates

### 일반 콘텐츠 슬라이드: L03~L10

좌표는 각 영역의 좌측 상단 시작점이다. 항목이 없는 경우에도 다른 영역을 당겨 올리지 않는다.

| 영역 | X | Y | 역할 |
|---|---:|---:|---|
| Header | 96 | 64 | 포트폴리오 및 프로젝트 식별 정보 |
| Eyebrow | 96 | 132 | 프로젝트·섹션 맥락 |
| H1 | 96 | 174 | 슬라이드의 핵심 메시지 |
| Subtitle | 96 | 322 | 핵심 메시지의 보충 설명 |
| Main Content | 96 | 400 | 본문, 차트, 표, 제품 경험 |
| Footer | 96 | 1004 | 페이지 및 보조 식별 정보 |

- Main Content 범위: **X96~1824, Y400~960**, 너비 1728px, 높이 560px.
- Header, Eyebrow, H1, Subtitle, Footer는 본문 레이아웃에 관계없이 같은 시작 좌표를 유지한다.
- 제목 영역은 Main Content를 침범하지 않으며, 본문은 Footer 영역을 침범하지 않는다.
- Header, Footer, Title Area, Slide Canvas는 공통 컴포넌트로 구현한다. Typography, Grid, Color도 중앙에서 관리한다.
- 시각적 다양성은 Main Content 안에서 구현하며 공통 영역의 좌표를 바꾸지 않는다.

### 예외 레이아웃: L01 Cover / L02 Section Divider

- 표지와 섹션 구분은 일반 콘텐츠 슬라이드의 고정 좌표 및 Main Content 범위와 다른 별도 레이아웃을 사용할 수 있다.
- 1920×1080, 16:9, 좌우 96px 안전 여백, 12-column grid 및 Typography·Color 규칙은 유지한다.
- Display와 제목·설명을 중심으로 구성하며 Header, Footer, Title Area의 배치 또는 생략은 해당 예외 레이아웃에서 공통으로 정의한다.
- 예외는 L01/L02에만 적용한다. 동일 Layout ID에서는 공통 컴포넌트와 동일한 배치 규칙을 재사용한다.

## 7. Layout Catalog & Selection

| Layout ID | 이름 | 용도 | 선택 기준 |
|---|---|---|---|
| L01 | Cover | 포트폴리오 제목, 지원자 및 핵심 포지셔닝 | 전체 포트폴리오의 첫 인상을 전달하는 표지 |
| L02 | Section Divider | 프로젝트·챕터 전환, 섹션 핵심 문구 | 독자의 맥락 전환과 시각적 호흡이 필요한 지점 |
| L03 | Editorial Narrative | 문제 정의, 인사이트, 판단 근거를 텍스트와 보조 그래픽으로 설명 | 수치보다 논리와 서사가 중심인 내용 |
| L04 | KPI Spotlight | 핵심 성과 수치와 비교 기준·한계를 강조 | 하나의 대표 성과를 빠르게 인식시켜야 할 때 |
| L05 | Before & After | 변경 전후의 정책·경험·결과를 대응 배치 | 같은 기준의 전후 차이를 보여줄 때. 인과효과로 단정하지 않음 |
| L06 | Data Analysis | 차트와 해석, 분모·기간·출처를 함께 제시 | 추세, 분포, 상관관계 등 데이터가 판단 근거일 때 |
| L07 | Process/Decision | 단계, 대안, 우선순위, 의사결정 흐름을 표현 | 실행 순서나 선택 이유를 설명할 때 |
| L08 | Product Experience | 실제 제품 화면과 사용자 흐름·정책을 연결 | 경험 변화가 핵심일 때. 임의 제작 화면은 실제 UI로 표현하지 않음 |
| L09 | Comparison Table | 여러 대안·지표를 같은 기준으로 비교 | 행·열 대응을 통한 정확한 비교가 필요할 때 |
| L10 | Conclusion/Next Steps | 교훈, 한계, 후속 계획과 검증 지표 | 프로젝트를 마무리하고 실제 수행과 향후 계획을 구분할 때 |

- 한 슬라이드에는 하나의 핵심 메시지와 그에 맞는 Layout ID를 선택한다.
- 반복적인 카드 배치를 피하되 다양성을 위해 공통 규격을 위반하지 않는다.
- L03~L10의 본문 배치, 차트·텍스트 구성, KPI 표현, 프로세스, 제품 화면 배치는 Main Content 안에서 유연하게 조합한다.
- 표·차트가 지정 영역에 들어가지 않으면 글자를 임의로 축소하지 말고 내용을 재구성하거나 슬라이드를 분할한다.

## 8. Reference Research & Design Workflow

### 레퍼런스 조사 조건

- 신규 제작/전체 리디자인 시 기존 지정 레퍼런스를 우선 확인한다.
- 기존 레퍼런스로 설명하기 어려운 콘텐츠나 특수 데이터 시각화가 있으면 해당 부분에 한해 추가 조사를 허용한다.
- 단순 수정 시 재조사를 금지한다.
- 사용자가 지정한 Riddes 메인 디자인과 쿠팡 컬러 방향은 임의로 변경하지 않는다.

추가 조사는 전체 스타일을 교체하는 근거가 아니다. 실제로 확인하지 않은 웹페이지나 시각 요소를 분석했다고 주장하지 않는다.

### 신규 제작/전체 리디자인 절차

1. BRIEF.md의 목적과 CONTENT.md의 검증된 콘텐츠를 확인한다.
2. Riddes와 쿠팡의 실제 화면을 확인하고 타이포그래피, 그리드, 여백, 그래픽 구성을 분석한다.
3. 지정된 컬러 시스템과 본 문서의 16:9 규격으로 재해석한다.
4. 표지(L01), 데이터 분석(L06), 성과 강조(L04)를 각각 1장씩 제작한다.
5. 실제 렌더링을 함께 비교하여 통일성을 검증한다.
6. 검증한 패턴을 나머지 슬라이드에 적용한다.

단순 수정은 기존 패턴과 본 문서의 규격을 적용하고 변경 범위를 검증한다.

## 9. Forbidden Patterns

- 기존 AI 생성형 PPT 템플릿으로 회귀하지 않는다.
- 모든 슬라이드를 동일한 카드 레이아웃으로 구성하지 않는다.
- 쿠팡의 다섯 가지 색상을 모든 페이지에 강제로 넣지 않는다.
- 레퍼런스를 이유로 공통 제목 위치를 변경하지 않는다.
- 컬러를 강조하려고 차트의 데이터 의미를 왜곡하지 않는다.
- 쿠팡의 공식 채용 자료로 오인될 수 있는 브랜딩은 사용하지 않는다.
- 기존 레퍼런스를 무시하고 임의의 디자인 방향으로 바꾸지 않는다.

## 10. Design Verification

- 모든 슬라이드의 1920×1080 / 16:9 및 비례 스케일링 확인
- 좌우 96px 안전 여백, 12-column grid, gap 24px 확인
- L03~L10의 공통 좌표와 Main Content 범위 확인
- L01/L02의 예외 적용 범위와 공통 패턴 확인
- 지정 Typography 크기·굵기 및 Header/Footer 일관성 확인
- 실제 렌더링에서 텍스트 잘림, 요소 겹침, 제목·본문·푸터 침범, 차트 가독성 확인
- 수치·분모·비교 기간·성과 귀속·한계를 CONTENT.md와 대조
- 코드 구현 시 가능한 빌드·실행 검증 수행. 수행하지 않은 검증은 완료했다고 보고하지 않음

## 11. Final Design Goal

Riddes에서 참고한 세련된 편집 디자인과 쿠팡의 다색 브랜드 아이덴티티를 조화롭게 결합한다.

최종 결과물은 쿠팡이 공식 제작한 자료처럼 보이기보다는, 쿠팡 Shopping에 지원하는 시니어 Product Leader가 자신의 역량을 정교하게 표현한 개인 포트폴리오처럼 보여야 한다.

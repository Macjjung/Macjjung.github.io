# Portfolio Design System

현재 기준: 2026-11-10 전체 리디자인. 이전 고정 좌표·pilot 규격은 폐기했다. 색상은 사용자 요청에 따라 기존 쿠팡 참고 팔레트를 유지한다. 과거 문서는 archive/에 보관한다.

## 디자인 방향
사용자가 지정한 최세화 포트폴리오의 색면, 단계 라벨, 문제·판단·실행 연결, 전후 비교, 실제 화면에 인접한 설명 방식을 참고한다. 페이지 순서만 가져오지 않고 정보 위계와 시각적 비중까지 구현한다. 타인의 경력·수치·화면을 자신의 증거로 쓰지 않는다.

## 공통 규격과 허용 범위
- 1920×1080, 16:9. 브라우저에서 전체 비례 축소. 이어 읽기는 너비와 상단 메뉴·상하 여백을 제외한 화면 높이 중 작은 쪽에 맞춰 한 장 전체가 들어오게 한다. 인쇄 크기는 별도로 유지한다.
- 기본 좌우 여백 80px. 헤더·푸터는 공통 컴포넌트.
- 화면 하단 탐색은 좌우 동일 폭의 3열 그리드로 중앙에 고정한다. 섹션명 길이·언어·페이지 자릿수가 바뀌어도 이전/다음 버튼 위치를 유지하며, 좁은 화면의 긴 섹션명은 말줄임한다.
- 일반 본문은 헤더 → 단계 라벨·제목·설명 → 본문 → 주석 → 푸터의 흐름 배치다. 개별 요소의 X/Y 좌표 고정 규칙은 없다.
- 프로젝트 표지는 전면 색면과 독립 제목 구성을 사용한다. 일반 표지에는 영문 세리프 제목을 사용한다.
- 사실·데이터 정의는 고정한다. 제목·본문 면적, 도식 크기, 색면, 행·열 구조는 핵심 메시지에 맞게 설계한다.
- 각 페이지에 의미 있는 시각적 중심을 둔다. 단순 위치 이동을 리디자인으로 간주하지 않는다.

## 색상
사용자가 지정한 Primary Red / Secondary Blue / 로고 멀티컬러의 역할을 구분한다. 참고작은 구성·도식·정보 위계만 참고하며 퍼플 색상을 사용하지 않는다.

| 역할 | 값 | 적용 |
|---|---|---|
| Primary Red | #E94B22 | 강조 텍스트·핵심 성과 숫자에만 사용 |
| Secondary Blue | #0074E9 | 프로젝트 표지, 텍스트 도형 채움·테두리, 연결선, 차트 |
| 로고 Blue | #3DACDC | 표지의 다색 구분선에만 사용 |
| 로고 Brown / Yellow / Green | #894F24 / #FAC000 / #80BC27 | 다색 구분선·작은 인덱스·프로젝트 역량 강조선 |
| 기본 글자 / 보조 글자 | #172033 / #526071 | 흰색·밝은 배경의 텍스트 |
| 밝은 강조 면 / 본문 배경 | #EDF5FF / #FAFCFD | 보조 면과 본문 |
| 구분선 / 악화·한계 | #DCE6F2 / #B63820 | 영역 구분·부정적인 결과 |

- 프로젝트 표지는 #0074E9와 흰 글자를 사용한다. #3DACDC를 표지 배경으로 사용하지 않는다.
- 임의로 만든 #007DA8 강조색은 제거했다. 강조는 Primary Red와 Secondary Blue로 구분한다.
- Red는 강조 글자에만 사용한다. 텍스트가 들어가는 도형을 Red로 채우지 않는다. 강한 도형은 Blue + 흰 글자, 보조 도형은 밝은 Blue + 짙은 글자를 사용한다.
- 기존 값은 회색, 변경 후 차트는 Secondary Blue. Green을 모든 긍정 성과에 사용하지 않는다.
- 전체 표지 구분선은 Brown → Secondary Blue → Yellow → Green → 로고 Blue다. 색만으로 상태를 구분하지 않는다.
- 적용 기준은 사용자가 제공한 [오빠두엑셀의 쿠팡 디자인 정리](https://www.oppadu.com/tools/design-systems-site/brand/coupang.html)다. 공식 쿠팡 가이드로 인증한 자료는 아니다.
- 로고를 재제작하거나 쿠팡 공식 채용 자료로 표시하지 않는다. 2026-11-11에는 사용자 PDF 피드백에 따라 04~07장의 문구와 배치를 수정했다.

## 타이포그래피
한글·본문: 운영체제 산세리프. 영문 표지·챕터 숫자: Georgia/Times New Roman. 외부 글꼴 다운로드 없이 동작한다.
- 표지 대표 제목: 182px. 프로젝트 제목: 76px.
- 일반 메시지 제목: 기본 48px. 본문 제목: 25~34px.
- 본문: 주로 22~28px. 보조 설명: 20~22px. 출처·측정 주석: 19px.
- 핵심 지표: 50~66px. 비교값: 25~29px.
이 값은 현재 구현의 기본 조합이며 변경 금지 규칙이 아니다. 새로운 표현에 필요하면 조합을 설계하고 실제 표시 크기에서 검수한다. 넘치는 내용을 무작정 축소하지 않고 정보 배치·편집을 먼저 해결한다.

### 도형 안 여백
2026-11-11 사용자 피드백에 따라 본문 크기를 약 10~15% 줄이고 카드 좌우 여백을 주로 32~40px, 위아래 여백을 26~36px로 늘렸다. 작은 단계 칸·표·레이블은 용도에 맞게 조정한다. 출처 글자는 축소하지 않는다. 제목과 설명 사이의 간격도 확보한다. 5장 승인 시안은 2026-11-11 원본에 반영했다. 6장 시안은 아직 별도로 유지한다.

## 실제 구현 패턴
`js/main.js`의 renderers는 데이터의 variant별 본문을 생성한다. 과거 L01~L10 메타데이터는 삭제했으며, 이름만 있고 구현이 없는 레이아웃 분류는 사용하지 않는다.

| variant | 시각적 구조 |
|---|---|
| cover | 중앙 세리프 제목 + 하단 역량 인덱스 |
| about | 좌측 최신순 경력 타임라인 + 우측 영역별 주요 경험 세로 목록(각 영역의 가장 최근 경험 기준 최신순) |
| contents | 큰 번호 + 프로젝트 편집형 목록 |
| project | 전면 Secondary Blue (#0074E9) + 큰 제목 + 세 개의 액션 탭. 마지막 탭에만 성과를 보조 표기 |
| strategy-decisions | 전략 제목 아래 문제 정의·개선 가설·제품 결정 카드. 두 전략의 독립 섹션 |
| dual-execution | 상단 정책·포지셔닝 설명 + 좌측 핵심 성과·우측 더 블랙 서비스 흐름 이미지 |
| members-results | 대표 성과 + 0 기준 세로 막대 + 단위가 붙은 전후 지표 |
| purchase-problem | 문제·분석·가설 + 고객 질문·정보·기대 행동의 대응 |
| purchase-execution | 대형 AS-IS / TO-BE 이미지 영역 + 상태·목표·직접 수령의 UX 결정 + 구매 구간별 보상 조정 |
| purchase-results | 참여자 3일 구매액의 0 기준 비교 막대·MAU 맥락 + 3개 보조 성과. 하단 별도 기존 분석 요약과 상세 대화상자. 비교 월·산식은 하단 주석으로 유지 |
| matching-problem | 문제 흐름 → 반응률 비교(0~0.5% 공통 축) + 유지한 정렬 수식·배정 판단. 문제 설명 21px/650, 라벨 20px로 승인 시안의 여백 유지 |
| matching-execution | 좌측 기존→변경 정책·등급별 호감 비중/주간 상한/측정 시점 점수컷 표, 우측 상한 결정 근거와 Trade-off. 후속 기대값 수식은 상세 보기 대화상자로 제공. 비중과 전환율을 구분하며 두 장 전용 규칙으로 한·영 배치 |
| matching-results | 1차 결과와 활동성·호감 누적의 후속 연구 |
| career-summary | 최신순 경력 요약과 세 실행 근거의 좌우 배치, 하단 기여 방향 |
| thank-you | 중앙 감사 인사·지원자 이름·역할, 충분한 여백 |

## 이미지와 차트
- `panels[n].image`에 `{verified:true,src:'assets/images/파일.png',alt:'설명',caption:'자료 성격·출처'}`를 넣으면 이미지가 표시되고 확대할 수 있다.
- verified가 아니거나 이미지가 없으면 확인된 내용의 설명도 또는 해당 페이지의 기본 편집을 표시한다. 06장 좌측 하단은 확인된 무료재화 핵심 성과를 표시한다. 우측 패널 아래는 사용자 제공 더 블랙 서비스 흐름 이미지를 원본 비율로 표시하며 클릭 확대를 지원한다.
- 실제 배포 여부가 확인되지 않은 기존 이벤트 설계 보드는 이번 본문에 사용하지 않는다.
- 차트는 0 기준 동일 척도. 확인된 두 시점만 표시하며 가상 추세·정책 시점·분포를 만들지 않는다.
- 단계 박스 너비·기하 도형은 측정량이 아니다. 수량·분포를 암시하는 가상 점·카드를 그리지 않는다.

## 언어별 구현
본문·고정 레이블·탐색 문구는 js/locales/ko.js와 en.js에서 관리하고, main.js의 마크업과 CSS는 공유한다. 영어 전용 줄바꿈·배치 보완은 `html[data-locale="en"]` 범위에 한정하며 한국어 레이아웃을 유지한다. 영어 17장은 번역·화면 검수 완료 상태이며 `lang="en"`으로 표시한다. 영어 제목 44px(한국어 48px), 프로젝트 표지 제목 68px(한국어 76px), 표지 본문 26px(한국어 28px), 부제 22px(한국어 23px)를 사용한다. 분석 주석 19px는 유지한다. 영어 전용 규칙은 Reading 규칙 앞의 단일 섹션에서 관리하며 전체 1920×1080 비례 축소를 유지한다. 제품 원본 안의 한국어는 영어 캡션으로 설명한다.

## 검수와 유지보수
전체 모음, 대표 장 확대, 노트북 너비 및 모바일 비례 축소, 키보드·목차·읽기·인쇄 전환을 확인한다. 원본 수치·조건은 CONTENT.md와 대조한다. 의미 있는 관계, 명확한 시각 중심, 장별 실루엣 차이도 검토한다.
CSS는 기본 → 공통 슬라이드 → 각 표현 패턴 → 화면·인쇄 순서로 관리한다. 과거 테마를 덮어쓰는 방식으로 패치를 쌓지 않는다. 이전 문서·검수 이력은 archive에 두고 활성 기준과 섞지 않는다.

10장은 사용자가 요청한 AS-IS/TO-BE 실제 화면 삽입 공간을 크게 확보한다. 사용자가 제공한 Before와 After 인포그래픽을 원본 비율로 표시한다. 추가 티켓 스토어 단계별 After는 To-Be의 단계별 화면 버튼으로 확대한다. 이미지 자체는 편집하지 않는다.

2026-11-12 · 7장 정보 위계: 사업 최종 성과(약 6배 성장·흑자전환)와 매출 그래프가 주강조다. 무료재화 전후 비교는 파란 면 없이 흰 배경 3열 표(구분/1월/6월)로 보조한다. 적용 후 열 제목·6월 값은 쿠팡 레드로 구분하며, 각 코호트 90일과 각 월 한 달의 집계 기준을 표 아래 명시한다.

2026-11-12 · 7장 강조 보완: 성장 그래프와 우측 지표의 열 비율은 1.5:1. 최종 MAU·ARPU, 무료재화 적용 후 열 제목과 수치, 더 블랙 상품 매출 금액은 Primary Red(#E94B22) 텍스트로 강조한다. 비교표는 흰 배경을 유지하고 막대그래프는 기존 Blue를 유지한다.


2026-11-12 · 02장: 회사별 경력 다섯 묶음, 재직 기간 18px·회사/직책 23px·역할 설명 18px. 오른쪽 영역별 경험은 유지한다.

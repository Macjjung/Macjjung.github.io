# 콘텐츠·시각화·공개 검토

사용자가 제공한 경력·성과에 기반하며 원본 증빙의 독립 검증은 수행하지 않았습니다. 각 프로젝트의 상세 사실은 Appendix raw 데이터에 보존했습니다. ‘검증된 성과’라는 추가 인증 표현은 사용하지 않습니다.

## 프로젝트별 시각화

- 더멤버스 전체 성장: 2024.02 20,227,900원과 2026.07 120,749,800원만 사용하는 두 막대 비교. 중간 월별 추정 데이터 없음. 약 5.97배·흑자 전환은 장기 제품 전체 성과.
- 무료 재화 정책: MAU 정규화 1.000→0.719, 소모 대비 무료 지급 91.90→44.46%, 유료 충전 63.92→71.10%, 상관계수 0.57→0.85. 보상 목적별 7일·30일·무제한 카드. 두 비율은 100% 구성비가 아님.
- 소개 로직: 카드 노출·호감 발신·발신율 전후 비교, 단계별 분모가 다른 발신·수락·번호 오픈 전환율. 0등급/4등급 수신 건수는 별도 비교. Appendix의 2×2 히트맵에서 알려진 두 조합만 색칠하고 나머지는 ‘자료 없음’. 실제 소개 슬롯 수 미제공으로 임의 슬롯 수를 그리지 않음.
- 파이브: 기존 서비스 통합과 별도 출시 의사결정 비교. 정보 비공개→만남 권장→무료 사후 확인 또는 티켓 사전 확인 흐름. 3.5개월·300명·첫 달 2,500만 원은 각 정의에 맞춰 표시. 특정 월별 출시 일정은 미제공.
- PG·OCR: 카드 촬영→OCR→PG 입력→등록→결제 키→재결제 흐름. 기존/개선 결제 UX 카드와 수수료 6%→3% 비교. 78%는 분모·기간 확인 필요.
- 헤디플: 사용자·미용실·결제수단별 요구를 설정형 정산으로 연결. 출시 기능과 운영 피드백 경로 명시. 점판 미출시.
- 호텔오더: 객실 상품 선택→결제→RUMY 주문 수신→처리→배송. 3개 실제 도입 사업장과 현장 역할.
- 바잉스퀘어: 이질적 카탈로그→비즈니스 요구사항→데이터 엔지니어 협업→B2B 카탈로그. 주문 시트→Apps Script·Zapier→담당자 알림은 카드에 별도 표시.
- 경력: 제공된 재직 기간과 프로젝트 기간을 구분한 타임라인. 임의 입사일 없음.

## 확인되지 않은 데이터

- A / economy-data, economy-results: 정책 분석 기간, 상관계수 산식, 동시 정책 변경, 매출·흑자 전환 증빙.
- B / matching-first, matching-next: 배포일 2026.08.28과 후 구간 시작 08.27의 차이, 각 단계 분모·집계 기준, 후속 개인화 설계 상태. 현재 미배포로 표시.
- C / five-results: 300명 전환 정의, 정보 확인 구매 수, ARPU·ARPPU 비교 기준. 불만·CX 문의가 거의 관찰되지 않았다는 진술을 불만 0건 또는 만남 증가로 해석하지 않음.
- D / payment-results: 간편결제 78%의 분모·기간, 매출 약 15% 관측 기간과 독립 기여도, 카드 처리 실제 범위. 매출 15%는 Appendix의 미검증 관측 기록으로만 보존.
- E / hediple-operations: DAU 300명의 시점·평균/최고치, 기능별 배포 시점. 점판 기능은 미출시.
- F / hotel: 사업장 자료·설치 화면·직원 가이드 원본.
- G / vibe: 데이터 모델·자동화 증빙. DB 스키마 직접 설계로 표현하지 않음.
- H / career, engineering: 더블유클럽 2022.01–2023.06, 트리플콤마 2024.02–재직중으로 사용자 확인 완료. 홍시호텔 CMS는 설계만 수행.

## 교체할 플레이스홀더

- closing 및 profile: 지원자 이름, 본인이 공개를 원하는 연락처, 이력서 링크.
- Appendix A–H: 실제 정책 문서·분석 원본·제품 화면·인터뷰 정리·운영 가이드·업데이트 기록·Notion 정리 등 자료 목록 전체.
- 모든 appendix.images는 빈 배열. 실제 제품·고객 화면을 모사하거나 가상 문서를 만들지 않음.
- 기존 assets 루트의 PNG는 검토하지 않았고 자동 재사용·배포하지 않음.

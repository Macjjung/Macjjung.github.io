## matching-journey 한 장 정돈 — 2026-11-10

### 수정 전 진단과 근거

- 실제 화면: 기본 브라우저 도구에서 `Sky Computer Use native pipe startup failed` 및 `browser access host is unavailable`. 대상 URL 열기·수정 전 캡처는 수행하지 못했다. 이전 선택대로 별도 Headless Chrome/Playwright를 사용하지 않았다.
- 코드상 정렬·간격: 7:5 상단과 280px 기반 하단의 기준선이 달랐고, 전송률 차트와 오른쪽 여러 지표의 대응 관계가 약했다. 실제 표시에서 중앙 쏠림·잘림이 어느 정도인지는 미확인이다.
- 정보 위계: 전송률의 상대 증가율 +11.2%가 표시되지 않았으며 노출 수·전송 건수가 서비스 전체 결제 설명 아래에 놓여 서로 다른 지표의 범위를 혼동할 수 있었다.
- 공간·차트: 기존 차트가 넓은 열을 점유했고 하단은 반복 결론과 전환 수치가 병렬 배치됐다. 실제 빈 공간과 과밀 정도는 브라우저에서 확인하지 못했다.
- CSS: 기존 matching 전용 네 규칙을 교체했다. 끝에 덮어쓰기를 쌓지 않고 신규 규칙을 기존 위치에 묶었다. 공통 캔버스·스케일·헤더·푸터·인쇄 코드는 변경하지 않았다.

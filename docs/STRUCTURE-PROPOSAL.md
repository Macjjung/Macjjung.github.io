## 1. 구성과 표현 원칙

- 전체 표지, About Me, Contents를 각각 둔다.
- 각 프로젝트에도 별도 표지를 둔다.
- 프로젝트 표지에는 프로젝트명, 실제 수행 내용 한 문장, 핵심 역량 하나, 확인된 기간·역할을 표시한다.
- 프로젝트당 표지 1장 + 본문 3장. 총 15장.
- 본문 공통 흐름: 문제·근거·판단 → 실행·제품 변경 → 결과·한계.
- 성과 숫자를 강조하되 과도한 크기나 반복으로 페이지를 채우지 않는다.
- 감성적인 슬로건, 비유, 자기평가 대신 관찰한 사실·결정·실행·결과를 쓴다.
- 시각화는 필요한 크기로 배치한다. 차트 하나를 크게 만드는 것보다 관련 설명과 근거가 함께 읽히게 한다.
- 비교 표, 짧은 설명, 전후 화면, 작은 도식을 목적에 맞게 조합한다. 카드 자체를 금지하지 않는다.
- 사실과 가설, 사업 전체 성과와 개별 변경의 효과, 실제 실행과 계획을 구분한다.
- 상세 내용과 지표 기준은 CONTENT.md를 보존한다. 불확실한 사실을 임의로 채우지 않는다.

### 05. 문제와 전략 — 고객 규모와 고객당 매출이 모두 제한적이었다

- 상황: 가입 조건과 연령대 차이만으로 서비스 선택·구매 이유가 충분하지 않았음.
- 기준 지표: 2024.02 MAU 2,670명, ARPU 7,562원, 월 결제액 20,190,500원.
- 판단 1: 초기 수익화 개선 → 무료재화 유효기간 도입 및 가입 지급량 조정.
- 판단 2: 높은 가격을 지불할 구매 가치 확보 → 모바일 결정사 포지셔닝과 더 블랙.
- 근거: 진지하지 않은 상대에 대한 게시판 불만, 결혼·결정사 소재의 마케팅 반응.
- 역할: 분석·문제 정의·기획·조율 수행. 정책·포지셔닝 방향은 임원진과 논의.
- 배치: 상단 기준 지표 3개를 작게, 본문에 문제 → 판단 → 실행의 2행 구조.
- CAC·코호트 자료는 시간·분모 정리가 되기 전 핵심 도표에 넣지 않는다.

### 06. 실행 — 무료재화 정책 변경과 만남 보장 상품 출시

- 2개 실행 영역으로 구성. 각 영역은 짧은 설명과 실제 화면을 붙인다.
- 영역 A: 무료재화 유효기간 도입. 가입 지급량은 첫 번호 오픈에 필요한 평균 수량을 기준으로 약 절반 조정.
- 이미지 A: 무료티켓 잔여량·유효기간 화면, 가입 보상 전후 안내. 핵심 부분을 읽을 수 있게 잘라서 배치.
- 영역 B: 실제 만남을 보장하고 미성사 시 100% 환급하는 더 블랙 출시.
- 이미지 B: 상품 소개와 환급 조건이 보이는 실제 화면.
- 본인 실행: 더 블랙 전체 기획, 국내결혼중개업 신고·등록 및 보증보험증권 발급.
- 확인되지 않은 유효기간 일수·범위·시행일은 만들지 않는다. 가입 지급량 변경일 2024.05.07과 구분한다.
- 이미지 빈칸 내부는 짧은 자료명, 아래에는 필요한 이미지 예시를 표시한다.

### 07. 결과 — 월 결제액 약 6배, ARPU 약 2.6배 증가

결과를 집계 범위별로 나눠 표시한다.
- 사업 전체, 2024.02 → 2026.07: MAU 2,670 → 6,120명, ARPU 7,562 → 19,730원, 월 결제액 20,190,500 → 120,749,800원. 담당 기간 중 흑자전환.
- 정책 적용 월, 2024.04 → 05: ARPU +56.7%, 월 결제액 +65.3%. 5월은 가입 지급량 변경 전후 혼합.
- 더 블랙: 월매출 800만~1,000만 원. 순증 효과로 단정하지 않음.
- 배치: 좌측에 검증된 월별 추이 또는 두 시점 비교 차트, 우측에 집계 범위별 결과 요약.
- 하단: 여러 제품·사업 활동이 함께 진행된 전후 관찰이며 특정 정책의 단독 효과로 귀속하지 않음.

## 4. 구매 이벤트 — 4장

### 08. 프로젝트 표지

제목: 구매 이벤트 개선
수행 내용: 티켓 구매 보상을 사후 일괄 지급에서 조건 달성 직후 직접 수령으로 변경하고, 달성 현황과 구간별 보상을 개편했다.
핵심 역량: 행동 데이터 기반 구매·보상 경험 설계
기간·직책: 확인된 자료에 있는 항목만 표시. 분석 기간을 수행 기간으로 대체하지 않음.

### 09. 문제와 가설 — 행사 이후 매출 하락과 보상 지급 시차를 검토했다

- 대상: 티켓 구매 시 보너스 티켓을 지급하는 이벤트.
- 관찰: 행사 이후 반복되는 구매 감소.
- 분석: 주요 구매층인 남성의 유료 구매·소비가 가까운 시점에서 강한 연관성을 보임.
- 가설: 이용 시점에 보상을 받을 수 있으면 실제 소비로 연결될 기회가 늘어날 수 있음.
- 역할: 문제와 보상 감축 규모는 임원진과 논의. 방식·상세 기획은 본인.
- 배치: 좌측 문제와 가설, 우측 원본 상관관계 자료 또는 설명용 지급 타임라인.
- 이미지 예시: 성별·시차별 구매–소비 상관관계 그래프. 확보 전 가상 데이터 곡선 금지.

### 10. 실행 — 달성 직후 수령과 보상 진행 현황을 연결했다

- 변경 1: 행사 종료 후 일괄 지급 → 조건 달성 직후 사용자 직접 수령.
- 변경 2: 현재 달성 단계·다음 보상·수령 버튼을 구매 및 사용 화면에 연결.
- 변경 3: 낮은 구매 구간 보상 축소, 높은 구간 혜택은 기존에 가깝게 유지.
- 배치: 상단 짧은 전후 흐름, 본문 실제 전후 화면과 3개 이내 주석.
- 이미지 예시: 기존 이벤트 안내 / 개편 후 프로그레스·보상 받기 화면.
- 직접 수령을 자동 지급으로 표현하거나 실제 총 지급량 30% 감소로 표현하지 않음.

### 11. 결과 — 참여자와 누적 결제금액이 증가했다

- 참여자 분석, 전후 각 5회: 평균 참여자 282.2 → 333.6명(+18.2%), 참여자 17일 누적 결제금액 평균 약 2,602만 → 3,059만 원(+17.6%).
- 서비스 전체 분석, 전후 각 4회: 17일 누적 결제 지수 0.992 → 1.022.
- 종료 후 매출 변화: 1~7일 -10.1% → -11.8%, 8~14일 -11.4% → -6.0%.
- 배치: 상단 주요 성과 요약, 중단에 두 주간의 작은 비교 차트와 지수, 하단 한계·후속 계획.
- 한계: 구매 절벽 해소는 확인하지 못함. 참여자 구매 지수 1.559 → 1.636, 소비 지수 1.170 → 1.212로 모두 상승했으나 소비 지수의 개선 폭이 작음.
- 후속 계획: 보상 수령 직후 사용 넛지. 실제 실행과 구분.
- 주석: 지수 = 누적 17일 결제액 ÷ (행사 직전 14일 일평균 결제액 × 17), 이벤트별 계산 후 평균. 지수 차이는 구매 대비 소비 비율이 아님.

수행 내용: 성별·등급별 반응 데이터를 분석하고, 기존 유사도 기반 소개의 카드 배정 비율을 조정했다.

### 13. 문제와 판단 — 유사도 기반 배정과 실제 반응의 차이를 분석했다

- 출발점: 사용자가 원하는 상대와 잘 연결되고 있는지 검토.
- 기존 방식: 일부 사용자 특성의 유클리드 거리 기반 소개.
- 분석: 성별·등급 조합별 호감 전송과 후속 반응.
- 판단: 반응 기여도가 낮은 조합을 축소하고 배정 비율 조정.
- 배치: 좌측 문제·판단, 우측 원본 분석표 또는 히트맵.
- 이미지 예시: 배정 판단에 사용한 성별·등급 조합별 반응률 자료. 수신자 등급별 결과표와 혼동하지 않음.
- 기존 로직을 등급별 균등 배정으로 표현하지 않는다.

### 14. 실행 — 실제 반응을 반영해 카드 배정 비율을 조정했다

- 기존: 사용자 특성 → 유사도 계산 → 카드 배정.
- 변경: 기존 기준을 실제 반응 데이터로 보완 → 낮은 반응 조합 축소·배정 조정.
- 측정: 노출 → 호감 전송 → 수락 → 번호 오픈, 실제 재화 소비와 결제까지 관찰.
- 배치: 상단 전후 개념도, 하단 사용자 행동 흐름과 관련 화면.
- 이미지 예시: 데일리카드·호감 전송·번호 오픈 실제 화면 중 맥락 설명에 필요한 1~2장.
- 개념도는 설명용이며 실제 미확인 시스템 구조·정확한 배정 비율은 만들지 않는다.

### 15. 결과 — 전송 효율·재화 소비는 증가, 후속 전환율은 하락

- 전후 각 50일: 노출당 전송률 0.639% → 0.711%(상대 +11.2%). 노출 +2.5%, 전송 건수 +14.1%.
- 활성 사용자당 데일리카드 소비 40.4 → 49.5스푼(+22.5%). 리매칭 등 포함.
- 같은 기간 서비스 전체 결제액 +6.9%, ARPU +8.5%는 별도 관찰로 구분.
- 후속 전환: 수락률 25.9% → 24.9%, 수락 대비 번호 오픈율 77.0% → 75.3%.
- 배치: 본문 좌측 전송률 차트와 노출·전송 건수, 우측 활성 사용자당 소비. 서비스 전체 결제액·ARPU는 별도 보조 행으로 분리하고 하단에 수락률·번호 오픈율 하락과 비교 기준을 둔다.
- 결론: 전송 효율은 개선됐지만 후속 전환율은 하락. 양방향 반응과 연결까지 고려할 후속 과제 확인.
- 기간: 2026.07.08~08.26 / 08.27~10.15. 월간 ARPU로 표현하지 않음.

## 6. 구현 기준

- 전체 표지와 프로젝트 표지는 정보 중심으로 구성한다. 감성 슬로건·장식용 이미지·거대한 숫자 없음.

## 사실 표현 조건
- 더멤버스 전체 성과는 2024.02~2026.07 사업 전체 관찰. 개별 정책 단독 효과가 아니다.
- 유효기간 도입과 2024.05.07 가입 지급량 조정은 구분. 보너스 재화 유효기간 7·30·90일은 사용자 피드백에 따라 반영. 종류별 매핑·도입일은 만들지 않는다.
- 더 블랙은 실제 만남 보장·미성사 시 100% 환급. 월 800만~1,000만 원은 순증 매출이 아니다.
- 구매 이벤트 보상은 사용자 직접 수령이며 자동 지급이 아니다. 설계 의도와 실제 소비 결과를 구분한다.
- 참여자 전후 각 5회, 서비스 전체 전후 각 4회. 첫 주 악화·둘째 주 완화를 모두 유지한다.
- 소개 로직은 유사도 기준의 보완이다. 기존을 등급별 균등 배정으로 표현하지 않는다. 실제 1차는 노출 상한·호감 기록 개선이다. 후속 기대값 계산은 적용 완료한 배정 점수가 아니다.
- 전후 각 50일, 수락률·번호 오픈율 하락, 배포일 경계 한계, 서비스 전체 지표와 기능 성과의 구분을 유지한다.
- 프로젝트 기간·직책은 제공된 영문 이력서와 대조했다. 구매 이벤트 서비스명은 사용자 확인에 따라 더멤버스로 반영했다. 미확인 비율·예외 처리·팀 규모는 추정하지 않는다.

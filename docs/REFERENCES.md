# Portfolio References

## 주 레퍼런스
사용자 제공 최세화 포트폴리오. 로컬 표준 경로: `references/portfolio-reference.pdf`.
사용자가 지정한 원본은 Downloads의 `최세화_포트폴리오.pdf`다. 표준 사본을 복구하며 내부 참고용으로만 사용한다. Git·배포에 포함하지 않는다.

이번 대화에서 실제 PDF의 23쪽 전체 축소 모음과 6·7쪽 확대 이미지를 확인했다. 최초 렌더러의 일부 한글 폰트 누락 때문에 원본 제목 문구를 추정하지 않았으며, 배치·색면·연결·화면의 비중을 참고했다.

## 적용할 시각적 특징
- 1~3쪽: 전체 표지, 프로필, 목차의 역할 분리. 영문 표지의 세리프 인상.
- 4·11·17쪽: 프로젝트 시작을 본문과 다른 색면·크기로 구분.
- 6쪽: 문제 → 해결 방향 → 개편 과제의 행별 대응, 화살표, 단계별 면 색상. 현재 05장에 적용.
- 7쪽: 변경 전후의 대응, 실제 화면과 설명의 인접 배치. 현재 10장은 확인된 UI 이미지가 없어 같은 원리를 사용자 흐름 비교로 적용.
- 전체: 연한 배경, 강조 면, 단계 라벨, 큰 정보 덩어리와 짧은 설명의 조합. 흰 배경·얇은 선만으로 축소하지 않는다.

색면·카드·연결선을 참고할 수 있다. 타인의 경력·숫자·기여도·실제 제품 화면을 자신의 자료로 사용하지 않는다. 참고 PDF의 가상 인터뷰나 예상 성과를 실제 수행으로 표현하지 않는다.

## 참고와 구현의 우선순위
사용자의 현재 시각적 요구 → 주 레퍼런스의 정보 표현 → 수정 가능한 디자인 시스템 순으로 판단한다. 사실·수치 정확성은 별도로 반드시 보존한다.
색상은 사용자 지정 Primary Red #E94B22와 Secondary Blue #0074E9를 따른다. 로고 멀티컬러(#3DACDC 포함)는 작은 구분선·인덱스에만 사용한다. 최세화 포트폴리오의 퍼플 색상은 사용하지 않는다. Riddes는 활성 디자인 기준에서 제외하며 이전 조사 기록은 archive에 남긴다.

## 검토 절차
대표 표지·전략도·전후 비교의 실제 이미지를 먼저 비교하고 전체 15장으로 확장한다. 공통 좌표 일치만 보지 않고 시각적 비중·관계·리듬을 검토한다. 지정 PDF를 찾지 못하면 사용자 제공 원본 경로를 확인하고 실제로 보지 않은 자료를 봤다고 기록하지 않는다.

2026-11-11 최신 색상 규칙: 쿠팡 Red는 강조 글자에만 사용하며 텍스트 도형 채움·테두리는 Blue 또는 밝은 Blue·중립색을 사용한다. 구매 이벤트 용어는 ‘이벤트’, ‘이벤트 기간’으로 통일한다.

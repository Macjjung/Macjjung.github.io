
# Design References

## 1. Primary Reference — Riddes

URL:
https://dribbble.com/shots/27875356-Platform-for-a-Reading-App-Riddes

### 역할
포트폴리오의 메인 디자인 레퍼런스.

### 적용 방향
- Editorial 기반의 정돈된 레이아웃
- 타이포그래피 중심의 정보 위계
- 충분한 여백과 그리드
- 세련된 그래픽 배치
- 일관된 시각적 디자인 언어

### 적용 규칙
- 신규 제작/전체 리디자인 시 실제 레퍼런스 화면을 먼저 확인한다.
- 레퍼런스의 구성 원칙을 16:9로 재해석한다.
- 원본 화면을 그대로 복제하지 않는다.
- 확인하지 못한 시각 요소를 추측하지 않는다.

## 2. Brand Reference — Coupang

URL:
https://www.coupang.com/

### 역할
포트폴리오의 컬러 아이덴티티 참고.

### 컬러 시퀀스
Brown → Red → Yellow → Green → Blue

### 적용 방향
- 기본 배경은 흰색
- 텍스트는 짙은 중립색
- 쿠팡 컬러는 강조 요소에 제한적으로 사용
- 표지 및 섹션 구분에 다색 컬러 스트립 활용
- 프로젝트 인덱스 및 주요 그래픽에 활용

### 금지 사항
- 다섯 가지 색상을 모든 슬라이드에 강제하지 않는다.
- 실제 쿠팡 로고를 임의로 변형하지 않는다.
- 공식 쿠팡 제작 자료로 오인될 디자인을 피한다.

## 3. Design System Relationship

REFERENCES.md는 시각적 영감을 제공한다.

전체 디자인 시스템의 단일 기준은 docs/DESIGN_SYSTEM.md다.
Canvas, Typography, 좌표, Grid, Layout ID, 컬러 및 검수 규칙은 해당 문서를 따른다.

반드시 유지할 규칙:
- 16:9 / 1920×1080
- 고정된 H1/H2/H3 규격
- 일반 콘텐츠 슬라이드(L03~L10)의 동일한 제목 시작 좌표와 고정된 Header / Footer
- 표지(L01)와 섹션 구분(L02)은 DESIGN_SYSTEM.md에 정의된 예외 레이아웃 적용
- 동일한 그리드와 안전 여백

레퍼런스 적용을 이유로
공통 슬라이드 규격을 변경하지 않는다.

## 4. Design Execution — 신규 제작/전체 리디자인

1. BRIEF.md에서 포트폴리오 목적 확인
2. CONTENT.md에서 프로젝트 콘텐츠 확인
3. 기존 지정 레퍼런스를 우선 확인
4. DESIGN_SYSTEM.md의 규격 적용
5. 표지, 데이터 분석, KPI 슬라이드 시안 제작
6. 실제 렌더링 결과 검토
7. 확정한 스타일을 전체 포트폴리오에 적용

단순 수정은 재조사나 전체 시안 제작 없이 기존 패턴과 DESIGN_SYSTEM.md를 적용하고 변경 범위를 검증한다.

## 5. Reference Research Policy

- 신규 제작/전체 리디자인 시 기존 지정 레퍼런스를 우선 확인한다.
- 기존 레퍼런스로 설명하기 어려운 콘텐츠나 특수 데이터 시각화가 있으면 해당 부분에 한해 추가 조사를 허용한다.
- 단순 수정 시 재조사를 금지한다.
- 사용자가 지정한 Riddes 메인 디자인과 쿠팡 컬러 방향은 임의로 변경하지 않는다.

추가 조사는 해당 콘텐츠의 표현을 보완하는 데 한정하며, 전체 스타일이나 지정된 메인 레퍼런스를 교체하는 근거가 될 수 없다.

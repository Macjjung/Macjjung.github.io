# Portfolio Brief

## 목적
쿠팡 Shopping Lead Product Manager 채용 검토자가 지원자의 문제 정의, 제품 판단, 실행, 성과 해석을 이해하고 면접에서 더 확인할 근거를 제공한다.

## 독자와 전달 내용
Product 리더·Hiring Manager·Recruiter가 빠르게 훑어볼 수 있어야 한다. 직함이나 추상적 자기평가보다 다음을 보여준다.
- 사업 문제를 제품 문제로 바꾸는 판단
- 행동 데이터와 고객 가치에 근거한 우선순위
- 정책·상품·경험을 구현한 실제 역할
- 사업 성과와 관측 한계를 함께 해석하는 능력

## 콘텐츠
사실과 수치는 CONTENT.md를 따른다. 17장: 표지·About Me·목차 + 더멤버스·구매 이벤트·소개 로직 각각 4장 + 경력·강점 요약 + 감사 인사. 마지막 요약은 확인된 경력과 실행 근거를 지원 직무에서의 기여 방향으로 연결한다. 상세 구성은 STRUCTURE-PROPOSAL.md.
전체 경력과 원문을 모두 본문에 넣지 않는다. 각 장의 핵심 메시지, 판단 근거, 실행, 관찰 결과를 편집한다. 비교 기간·분모·부정적 결과를 생략하지 않는다.

한국어·영어는 같은 17장 구조와 구현을 공유하고 콘텐츠 파일을 분리한다. 한국어가 사실의 기준 원문이며, 영어는 쿠팡 Product 리더가 판단·실행·성과를 이해하도록 문맥 중심으로 번역했다. 실제 결제액·재화 구매·소비는 구분하고 인과효과를 확대하지 않는다. 언어별 관리 기준은 LANGUAGES.md를 따른다.

## 독서 경험
사용자가 지정한 최세화 포트폴리오처럼 색면·단계 라벨·관계도·전후 비교로 정보의 구조가 먼저 보이게 한다. 정확성을 작은 글과 표 위주 표현으로 오해하지 않는다. 큰 도식·강조 수치는 메시지에 기여하는 범위에서 사용한다. 색상은 사용자 지정 Red #E94B22·Blue #0074E9를 중심으로 사용하며, 일관된 서체·팔레트 안에서 페이지 목적에 따라 구성을 달리한다.
실제 화면이 없을 때는 확인된 사실의 설명도를 만들거나 빈칸 없이 배치한다. 06장은 사용자 요청에 따라 좌측 하단에 확인된 핵심 성과를 배치하고, 우측에는 사용자 제공 더 블랙 서비스 흐름 이미지를 표시한다. 실측 자료·실제 UI와 개념 설명을 구분한다.

## 성공 기준
어떤 문제를 발견했고, 왜 그 선택을 했으며, 무엇을 바꿨고, 결과를 어떻게 해석했는지 빠르게 이해할 수 있어야 한다. 세 사례에서 커머스에 연결할 수 있는 제품 전략·구매 경험·추천 최적화 역량을 드러낸다.
디자인 품질은 참고작과의 시각적 비교 및 실제 렌더링으로 평가한다. 현재 작업은 로컬 파일 수정이며 온라인 게시와 구분한다.

2026-11-11 최신 색상 규칙: 쿠팡 Red는 강조 글자에만 사용하며 텍스트 도형 채움·테두리는 Blue 또는 밝은 Blue·중립색을 사용한다. 구매 이벤트 용어는 ‘이벤트’, ‘이벤트 기간’으로 통일한다.

구매 이벤트 09~11장은 고객의 혜택 이해 → 다음 목표 판단 → 직접 보상 수령이라는 정보·행동 설계를 강조한다. 실제 상품 탐색·기획전 운영 실적을 새로 주장하지 않으며, UX 배치의 시각적 증거는 10장의 변경 전후 화면으로 보완한다.

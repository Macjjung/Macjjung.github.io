# 11장 구성

01. cover — 사용자 문제를 사업 성과로 연결하는 Product Manager
02. impact — 문제를 발견하는 것부터 제품의 결과를 검증하는 것까지
03. economy — 무료 재화 공급 구조에서 수익화의 문제를 발견했습니다.
04. economy-data — 지급 목적에 따라 재화의 유효기간을 차등 설계했습니다.
05. five — 기존 브랜드의 정체성을 유지하면서 새로운 서비스를 출시했습니다.
06. five-results — 사용자 인터뷰에서 발견한 요구를 제품 정책으로 구현했습니다.
07. matching — 한정된 소개 기회를 사용자 반응에 맞춰 재배분했습니다.
08. matching-next — 호감 발신 효율을 개선하고, 최종 전환을 고려한 후속 기획으로 연결했습니다.
09. leadership — 사례 추가 예정
10. leadership-results — 사례 추가 예정
11. closing — 문제를 정의하는 것에서 끝나지 않고, 실제 제품 결과로 연결합니다.

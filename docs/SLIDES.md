# 전체 슬라이드 목차

01. `cover` — INTRO — 문제를 정의하고, 제품으로 답합니다.
02. `about` — INTRO — 기술을 이해하는 PM 실행까지 책임지는 오너
03. `impact` — INTRO — 숫자로 보는 제품 경험
04. `career` — INTRO — 개발에서 제품으로, 제품에서 사업으로.
05. `economy` — 01 / 더멤버스 · 재화 정책 — 기능을 더하기 전에, 경제 구조부터 바꾸다.
06. `economy-data` — 01 / 더멤버스 · 재화 정책 — 성장하는 사용자 수에 가려진 재화의 흐름
07. `economy-decision` — 01 / 더멤버스 · 재화 정책 — 같은 무료 재화, 다른 지급 목적.
08. `economy-results` — 01 / 더멤버스 · 재화 정책 — 정책의 결과와 제품 전체의 성장을 구분합니다.
09. `matching` — 02 / 더멤버스 · 소개 로직 — 추천 슬롯을, 더 의미 있는 기회로.
10. `matching-exposure` — 02 / 더멤버스 · 소개 로직 — 동일한 배분이 동일한 기회를 만들까요?
11. `matching-first` — 02 / 더멤버스 · 소개 로직 — 노출은 +2.5%, 호감 발신은 +14.1%.
12. `matching-next` — 02 / 더멤버스 · 소개 로직 — 중간 지표 다음의 사용자 행동까지.
13. `five` — 03 / 파이브 · 신규 출시 — 브랜드는 지키고, 새로운 시장은 열고.
14. `five-brand` — 03 / 파이브 · 신규 출시 — 확장할 것은 시장, 유지할 것은 브랜드.
15. `five-research` — 03 / 파이브 · 신규 출시 — 선입견 없이 먼저 만나보자.
16. `five-results` — 03 / 파이브 · 신규 출시 — 사용자 경험 안에서 수익화의 기준을 설계하다.
17. `payment` — 04 / PG·OCR · 간편결제 — 결제의 마찰은 줄이고, 사업의 효율은 높이고.
18. `payment-architecture` — 04 / PG·OCR · 간편결제 — 직접 만들 부분과 연결할 부분을 구분하다.
19. `payment-results` — 04 / PG·OCR · 간편결제 — 재화가 부족해도, 이용 흐름은 이어지도록.
20. `hediple` — 05 / 헤디플 · 개인 서비스 — 매일의 작은 불편에서 시작한 나의 제품.
21. `hediple-design` — 05 / 헤디플 · 개인 서비스 — 다양한 요구를 설정 가능한 구조로.
22. `hediple-operations` — 05 / 헤디플 · 개인 서비스 — 출시는 시작, 피드백은 다음 설계.
23. `hotel` — 06 / 호텔오더 · B2B2C — 객실의 주문을 현장의 실행까지.
24. `hotel-operations` — 06 / 호텔오더 · B2B2C — 새 제품을 기존 운영에 자연스럽게 연결하다.
25. `vibe` — 07 / 바잉스퀘어 · B2B — 다른 데이터를 연결하고, 반복 업무를 줄이다.
26. `engineering` — EXPERIENCE / ENGINEERING — 제품 판단의 기반에는 직접 만든 경험이 있습니다.
27. `principles` — CLOSING — 제가 제품을 만드는 방식.
28. `closing` — CLOSING — 다음 제품의 문제를, 함께 풀고 싶습니다.
